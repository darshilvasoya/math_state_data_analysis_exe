# Math State Data Analysis (with Executable)

This repository contains Jupyter Notebook files and their compiled executable versions for **mathematical and data analysis experiments**.

## 📂 Project Structure
- `ch-*` → Chapter-wise practice notebooks
- `exe-*` → Executable builds of selected notebooks
- `.ipynb` → Jupyter notebooks for analysis
- `.exe` → Standalone executables created from notebooks (via PyInstaller / nbconvert)

## 🚀 How to Use

### Run Notebook
1. Install [Jupyter Notebook](https://jupyter.org/) or [JupyterLab](https://jupyterlab.readthedocs.io/).
2. Open the desired `.ipynb` file:
   ```bash
   jupyter notebook your_notebook.ipynb
